Weidmüller (Weidmueller Interface GmbH & Co. KG, headquartered in Detmold, Germany) is a provider of smart industrial connectivity and automation: terminal blocks, PCB connectors, electronics, I/O systems, controls and industrial Ethernet. Its u-OS edge operating system for automation devices (UC20 controllers) exposes a Data Hub with documented Variable-HTTP and Variable-NATS APIs, whose OpenAPI and AsyncAPI specifications are published in the weidmueller GitHub organization.

**Areas:** Company · Industrial Automation · Industrial Connectivity · Edge Computing · Industrial IoT · u-OS · Manufacturing
